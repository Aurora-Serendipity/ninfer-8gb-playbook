### 3.3 怎么自己核一遍

```powershell
# 引擎哈希（本机 sm89 件）
Get-FileHash -Algorithm SHA256 .\10-engine\engines\sm89\infer-serve.exe

# 模型件哈希与长度
Get-FileHash -Algorithm SHA256 .\20-model\models\bonsai2_27b_ternary_ptq1_native_mtp.ninfer
(Get-Item .\20-model\models\bonsai2_27b_ternary_ptq1_native_mtp.ninfer).Length

# 一键版（仓库 scripts\ 里的脚本，放到 30-scripts\ 后）
powershell -NoProfile -ExecutionPolicy Bypass -File .\30-scripts\check-model.ps1
```

`check-model.ps1` 同时校验**字节数 + SHA256 + 引擎侧硬链接是否同一份字节**，判据：

```text
MODELCHECK_VERDICT=OK
MODELCHECK_BYTES=OK
MODELCHECK_HASH=OK
```

## 5. 两档配方基线（数字来源：本机 2026-10-23 实测）

| 项                             | 日常 `8g-daily`       | 长档 `8g-longctx`   |
| ------------------------------ | --------------------- | ------------------- |
| 卡容量 / 预留 / 桌面           | 8,188 / 400 / 300 MiB | 同左                |
| 红线 = 容量 − 预留 − 桌面      | **7,488 MiB**         | **7,488 MiB**       |
| 引擎预估（预算闸门）           | **7,421**（余 67）    | **7,312**（余 176） |
| 实测显存峰值                   | **7,015 MiB**         | **7,171 MiB**       |
| dtype                          | `rk2v4-e8`            | `rk2v4-e8`          |
| 页大小 / 池页数                | 64 token / 200 页     | 64 token / 800 页   |
| 逻辑页数（`--max-context`/64） | 2,048                 | 4,096               |

> 预算闸门公式（启动器内置）：`engine = base + pages × slope`，`ptq1` 开 MTP 基线 7254、
> 无投机基线 6643，`rk2v4-e8` 斜率 0.8357 MiB/页；`红线 = 卡容量 − reserve − desktop`。
> 日常档 `7254 + 200×0.8357 = 7421`；长档 `6643 + 800×0.8357 = 7312`。**不达标启动器直接拒启。**

## 7. 哪些数字可以照抄，哪些必须重测

| 类别           | 例子                                                                              | 换机器后                                |
| -------------- | --------------------------------------------------------------------------------- | --------------------------------------- |
| **结构性事实** | 端口 8080/8081/8720、model id `j27b`、参数名与语义、四桶预算恒等式、页 = 64 token | ✅ 可以照抄                             |
| **判据**       | `7*5`→`35`、`+2`→`37`、4/4 请求、`RESULT: PASS`、预算闸门 ≤ 红线                  | ✅ 可以照抄                             |
| **速度类数字** | decode 63~72 / 20 tok/s、prefill 610~697、TTFT 1.7 s、启动 3.3~3.6 s              | ❌ **必须重测**                         |
| **显存类数字** | 峰值 7,015 / 7,171、红线 7,488                                                    | ⚠️ 换卡必须按"卡容量 − 预留 − 桌面"重算 |
| **负结果**     | 网关 L1 丢弃超大单条消息、超池静默丢中段                                          | ⚠️ 机制可参考，**幅度/触发点需重测**    |

> 上游参考机（RTX 4080 SUPER，16 GB）的解码档位是 **100~275 tok/s**（快档），本机日常档是 **63~72 tok/s**。
> 同一个模型、同一套判据，差数倍——这就是为什么"照用数字"是错的。

## 8. 路径约定（会影响能不能跑起来）

- **部署根目录必须是纯 ASCII 路径**（例如 `D:\llm-deploy\`）。历史坑：非 ASCII 目录 + 无 BOM 的 `.ps1`
  会被 PowerShell 5.1 按 ANSI 读 ⇒ 路径静默乱码 ⇒ **检查全绿但对象不存在**。
- 启动器与脚本内部全部使用**相对路径**（`%~dp0..`），所以整个目录可以整体搬走，
  只要保持 `10-engine\` / `20-model\` / `21-launchers\` 的层级关系。
- 批处理启动器**必须是纯 ASCII、无 BOM**（含注释）：cmd 会按 OEM 代码页解析 `.bat`，
  非 ASCII 字节会让注释行变成命令。
- 仓库 `.gitattributes` 已钉死策略：`.bat` / `.ps1` = **CRLF**，`*.md` = **LF**。检出后不要手工改换行。
