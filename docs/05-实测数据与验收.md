# 05 · 实测数据与验收

> 这一篇是我们**全部实测读数**的留档：怎么量、量到多少、什么算通过、什么还没验。
> 换机器 / 换驱动 / 换参数后**必须重测**，不要把这些数字当预期值。

---

## 1. 先约定：哪个读数才算数

| 优先级 | 读数                            | 说明                                                                              |
| ------ | ------------------------------- | --------------------------------------------------------------------------------- |
| ★★★    | 引擎日志 `req#N done …` 行      | 请求级权威读数（prompt / output / cache / TTFT / total / prefill / decode / MTP） |
| ★★★    | 客户端响应 `usage` 与 `timings` | 与日志互相对账                                                                    |
| ★★     | `nvidia-smi` 采样               | 显存峰值；红线 7,488 MiB                                                          |
| ★★     | `capacity` 行                   | 池大小 / dtype / 页数 / runtime / free                                            |
| ★      | UI/日志里的 `throughput \| …`   | **瞬时值，不可跨时间比较**                                                        |

**测试口径**（下表全部同口径）：

- 机器：RTX 4060 Laptop 8 GB（sm_89）、驱动 616.64、32 GB 内存、Windows x64
- 单用户单路；`temperature=0`；`thinking off`（`--default-reasoning-effort none`）
- 两档都带 `--no-cuda-graph`、`NINFER_HOST_PAGEABLE=1`
- 方法：`10-engine\启动器.bat` 选档启动（或 21-launchers 一键脚本）→ 直连引擎 8080 发 OpenAI 请求；
  `nvidia-smi` 采样；读数取自引擎日志与响应

## 4. 输出长度（本机两个理想值，都可达）

| 档   | 目标      | 实测                                                                                                                            |
| ---- | --------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 日常 | **4,096** | **可达**：`max_tokens=4096` 计数语料 `finish=length`，completion **4,096**（draft=4 后长输出约 63~72 tok/s，4k 输出约 60~65 s） |
| 长档 | **8,192** | **可达**：`max_tokens=8192` 计数语料 `finish=length`，completion **8,192**（404.6 s，decode 20.3 tok/s）                        |

> 复验：`verify-v2-basic.ps1 -Tier daily -OutputTokens 4096`（慢，跑几分钟）。
> 约束来自上游 B35：**题面 + 输出 ≤ 池**。日常档建议单条题面 ≤ 8,192、长档 ≤ 42,496（网关输入预算），
> 否则先分段/分片。

## 5. 速度（计数语料，温度 0）

| 指标                     | 日常档（draft 4）                                | 长档（无 MTP）        |
| ------------------------ | ------------------------------------------------ | --------------------- |
| decode                   | **63.3 ~ 71.6 tok/s**（短请求 30~38 含固定开销） | **20.3 ~ 21.4 tok/s** |
| prefill                  | 640 ~ 697 tok/s                                  | 610 ~ 675 tok/s       |
| TTFT（1,121 token 题面） | 1.7 s                                            | —                     |
| 1,000 token 输出总耗时   | 14.4 s（输出 804 时）                            | —                     |

> 上游参考机（RTX 4080 SUPER）的 8G 快档 decode 是 100~275 tok/s（MTP accept 77~92%）。
> 本机 63~72 tok/s 是同一机制在笔记本 8 GB 卡上的实测值——**不要拿它当"性能只有 1/4"的结论**，
> 它同时受卡、功耗墙、池大小与 MTP 接受率影响。

## 8. 怎么自己复现这套验收

```powershell
# 1) 启动日常档（脚本自己会做预检 + 真请求验证）
.\21-launchers\start-daily.bat

# 2) 真请求判活
powershell -NoProfile -ExecutionPolicy Bypass -File .\21-launchers\healthcheck.ps1
#    期望末行 [PASS ] the engine is really serving.

# 3) 运行中基础验收
powershell -NoProfile -ExecutionPolicy Bypass -File .\30-scripts\verify-v2-basic.ps1 -Tier daily
#    期望末行 RESULT: PASS

# 4) 可选：长输出（很慢）
powershell -NoProfile -ExecutionPolicy Bypass -File .\30-scripts\verify-v2-basic.ps1 -Tier daily -OutputTokens 4096

# 5) 切成长档（脚本会自动停掉日常档），重复 2) 3)
.\21-launchers\start-long.bat

# 6) 停机 + 复核
.\21-launchers\stop-daily.bat
nvidia-smi --query-gpu=memory.used --format=csv,noheader,nounits
#    期望回到空闲值（停机后引擎占用的 ≈7 GB 显存全部释放）
```

**包与模型校验**（不需要引擎在跑）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\30-scripts\verify-engine-package.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\30-scripts\check-model.ps1
```
