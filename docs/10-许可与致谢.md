## 2. 本仓库**不**收录什么（重要）

| 内容                                                             | 原因                                                                     |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **引擎二进制**（`ninfer-serve-89.exe` 及运行期 DLL，约 1.4 GiB） | 由上游发布，本仓库不分发                                                 |
| **模型权重**（`.ninfer` 模型件，5.96 GiB）                       | 由上游发布，且权重有各自的许可                                           |
| **上游作者的文档原文**                                           | 版权归上游；本仓库只做**引用与重述**，不复制原文                         |
| **上游的内部缺陷账本原文**                                       | 同上。本仓库只写**我们本机实测复现过的**现象与处置，需要对照时按编号指路 |
| **任何凭据 / API Key / Token**                                   | 见 §5                                                                    |

> 因此，**本仓库不能独立"开箱跑起来"**：你需要先从上游获取引擎与模型件
> （步骤见 [03 · 部署路线](03-部署路线.md)）。本仓库提供的是**适配层与判据**。

## 5. 安全与隐私提醒

- 本仓库**不含任何凭据**。发布前已对全部脚本做过凭据扫描（命中的 `token` 全部是 `max_tokens` 参数）。
- **不要把 API Key、访问令牌、内网地址写进启动器或客户端配置文件后提交到公开仓库。**
  本方案涉及的客户端配置（MCP 服务器等）**经常带明文令牌**，提交前务必检查。
- 本服务**没有鉴权**，只应监听 `127.0.0.1`。**不要**改成 `0.0.0.0`，也不要端口转发到公网。
