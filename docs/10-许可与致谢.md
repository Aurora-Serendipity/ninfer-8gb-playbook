## 3. 上游项目（引擎与工具）

### 3.1 直接上游：NInfer Fusion KVMem

- **仓库**：<https://github.com/1314521gjy/ninfer-fusion-kvmem>
- **许可**：**Apache-2.0**（原文见上游 `LICENSE`）
- **定位**：NInfer `0.11.0` 线（KVMem 融合线）的**下游衍生项目**；2026-10-19 的 sm86 / sm89 / sm120a
  三份引擎由同一份源码各自编译（本方案使用其中的 **sm89 件**，sha256 `3B6F9AF9…5EF6E4`）。
- **本仓库使用它发布的**：三 arch 分发包（引擎 + 启动器 + 网关 + 控制台 + runtime）、
  以及（可选）源码仓 `tools\` 下的 `agg_gateway.py` / `kv_plan.py` / `accept_8g.py`。

### 3.2 基座与第三方算法来源（上游 `NOTICE.md` 所述）

上游 Fusion KVMem 是 NInfer 的**下游衍生**（以 `ashalliants/ninfer-3090` 的 `master`，
`VERSION = 0.11.0-rtx3090` 为基线），其 `NOTICE.md` 给出的基座与第三方来源（均为 **Apache-2.0**）：

| 仓 / 来源                                                                 | 角色                                                                          |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |

| [`ashalliants/ninfer-3090`](https://github.com/ashalliants/ninfer-3090)   | 引擎树 README 自称的基线（`master`）                                          |

## 6. 安全与隐私提醒

- 本仓库**不含任何凭据**。发布前已对脚本做过凭据扫描（命中的 `token` 全部是 `max_tokens` 参数）。
- **不要把 API Key、访问令牌、内网地址写进启动器或客户端配置文件后提交到公开仓库。**
  本方案涉及的客户端配置（DSH provider、MCP 服务器等）**可能带明文令牌**，提交前务必检查。
- 本服务**没有鉴权**，只应监听 `127.0.0.1`。**不要**改成 `0.0.0.0`，也不要端口转发到公网。
- 本地模型完全离线，但**客户端/插件**可能联网——注意区分。
